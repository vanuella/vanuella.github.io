🚫 ELIGIBILITY RESTRICTIONS (Australia)

Triple J Unearthed:

To upload as an artist, you must be an Australian citizen or resident. If Vanuella doesn't meet this requirement, skip this platform.

AMRAP (Australian Music Radio Airplay Project):

AMRAP uploads must be by Australian artists who are citizens or ordinarily residents of Australia. Producer/location doesn't qualify.

✅ Alternative Strategy: If not AU-eligible, swap these for direct station pitching (still totally valid and effective!)

💰 ROYALTIES ADMIN (DON'T SKIP!)

Register BEFORE radio airplay so you get paid for every spin:

  • APRA AMCOS - Performance rights (songwriter/publisher royalties)
  • PPCA - Neighboring rights (artist/label royalties for recordings)

These registrations are specifically recommended in AU radio pitching guidance.

📦 RADIO PACK ASSETS REQUIRED

Prepare these assets to remove friction for radio presenters:

  • Radio one-sheet PDF - Artist bio, track info, RIYL (Recommended If You Like), contact details
  • Clean/radio edit - If applicable (clearly label if explicit version exists)
  • High-quality files - WAV or 320kbps MP3
  • Album artwork - High-res (3000×3000px minimum)
  • Press photo - High-res for promotional use

RADIO SERVICING RULES - Universal Checklist

✅ Universal Rules (Keep You Out of the Bin)

  1. Follow each station's submission page exactly - They vary a lot!
  2. Do NOT send audio as email attachments (most stations explicitly don't want it). Provide:
    • Stream link (SoundCloud/Bandcamp/YouTube - unlisted/private OK)
    • Download link to WAV or 320kbps MP3 (free to download, no login required)
  3. No logins, no expiring links:
    • Triple R: Stream must not require login, download links should not expire
    • RTRFM: "Please do not attach them to your email" + downloadable WAV/MP3
  4. Label files cleanly:
    • VanuellaWatt_ANGEL_RadioEdit_320.mp3
    • VanuellaWatt_ANGEL_16bit44k1.wav
  5. Include minimum metadata in email:
    • Artist / Track / Release date / Genre
    • ISRC (and UPC if you have it)
    • Clean/explicit flag
    • RIYL (3 comparable artists)
    • Short bio + press photo link + cover art link
    • Contact (name, email, phone, timezone)
  6. Send early: Some stations want ~2 weeks ahead for premieres/consideration (RTRFM says this explicitly)
  7. Register for royalties: APRA AMCOS + PPCA so airplay earnings are captured
